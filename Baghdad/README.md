# تطبيق بغداد

## الوصف

تطبيق مكتبي متكامل مصمم ليكون بديلاً لـ Microsoft Office مع وحدة محاسبة مدمجة. تم بناء التطبيق باستخدام C# و Avalonia UI لضمان عمله على أنظمة تشغيل متعددة (Windows, macOS, Linux).

## الحالة الحالية

المشروع في مراحله الأولية. تم إعداد الهيكل الأساسي للتطبيق ويشمل:
- نافذة رئيسية بواجهة تدعم اللغة العربية (من اليمين إلى اليسار).
- قائمة علوية أساسية (تحتوي على ملف، تحرير).
- إعدادات اللغة والثقافة الافتراضية هي العربية العراقية.

## كيفية التشغيل

لتشغيل التطبيق في بيئة التطوير، تأكد من تثبيت .NET 8 SDK ثم قم بتنفيذ الأمر التالي من المجلد الرئيسي للمشروع:

```bash
dotnet run --project .
```

## الخطوات القادمة

- بناء وحدات تحرير المستندات (Docs), الجداول الإلكترونية (Sheets), والعروض التقديمية (Slides).
- إضافة وحدة المحاسبة.
- ربط قاعدة البيانات المحلية SQLite.
